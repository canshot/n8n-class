# [실습] GitHub Codespaces로 n8n 시작하기

본 실습은 **GitHub Codespaces**를 활용하여 별도의 프로그램 설치 없이 웹 브라우저에서 **n8n(자동화 툴)**을 실행하는 실습입니다. 아래 3단계 안내에 따라 실습 환경에 접속해 주세요.

---

## n8n 접속 가이드 (3단계!)

### 1단계: Codespace 생성하기

1. 현재 보고 계시는 GitHub 저장소 상단의 초록색 **`[ ← Code ]`** 버튼을 클릭합니다.
2. 팝업창에서 **`[Codespaces]`** 탭을 선택합니다.
3. **`[Create codespace on main]`** (또는 초록색 대형 버튼)을 클릭합니다.
   * *새 탭이 열리며 가상 실습 컴퓨터가 빌드됩니다. 약 1~2분 정도 소요되니 잠시 기다려 주세요.*

### 2단계: n8n 웹 화면 열기

1. 빌드가 완료되면 VS Code 화면이 브라우저에 뜹니다.
2. 우측 하단에 **"5678 포트가 열렸습니다. 브라우저에서 여시겠습니까?"**라는 알림창이 뜨면 **`[Open in Browser]`**를 클릭합니다.
3. 만약 알림창을 놓쳤다면?
   * 화면 하단 탭 메뉴 중 **`[Ports]`** 탭을 클릭합니다.
   * 목록에 있는 `5678` 포트의 **`Local Address` 지구본 아이콘**을 클릭하면 n8n 화면이 열립니다.

### 3단계: n8n 초기 계정 생성 및 시작

1. 새 창으로 n8n 메인 화면이 열리면 성공입니다!
2. 실습에 사용할 **이메일, 이름, 비밀번호**를 입력하여 초기 마스터 계정을 생성합니다.
   * *이 계정 정보는 외부로 공유되지 않으며 본인 실습용 컴퓨터에만 저장됩니다.*
3. 로그인이 완료되면 교수님의 안내에 따라 실습 워크플로우를 생성합니다.

---

## ⚠️ [중요] 실습 종료 후 반드시 지켜야 할 사항

GitHub Codespaces는 매월 무료 사용 시간(60시간)이 정해져 있습니다. 실습이 끝난 후 그냥 브라우저 창만 닫으면 가상 컴퓨터가 계속 켜져 있어 무료 시간이 낭비됩니다. **반드시 아래 방법으로 종료해 주세요.**

1. VS Code 화면 좌측 하단의 **파란색/초록색 원격 아이콘(`><` 모양)**을 클릭합니다.
2. 화면 상단에 뜨는 메뉴에서 **`[Stop Current Codespace]`**를 클릭하여 컴퓨터를 완전히 꺼줍니다.
